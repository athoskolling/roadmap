Salvar na nuvem

O progresso fica salvo neste navegador automaticamente. Para ter uma cópia na nuvem, conecte um Gist secreto do seu GitHub. Ele é gratuito e não precisa de servidor.

Como criar o token

GitHub → Settings → Developer settings → Personal access tokens → Tokens (classic). Marque apenas o escopo gist. O token fica só no localStorage deste navegador e nunca vai para o repositório.
